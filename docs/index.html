Chaco-256

Modern high-security encryption library for Python & Rust

Get Started View on GitHub

Install in seconds

python -m pip install chaco256

Features

256-bit Keys

Maximum security with 2^256 key space. Post-quantum resistant.

High Performance

Optimized ARX operations for 64-bit processors. 3-5 GB/s throughput.

AEAD Support

Authenticated encryption with 256-bit tags. Detect tampering instantly.

Constant-Time

Side-channel resistant. No timing attacks or cache leaks.

Multi-Language

Python, Rust, and C/C++ support. Same API everywhere.

192-bit Nonces

Collision-resistant. Safe random nonce generation.

Quick Start

Security Notice: Chaco-256 is a new design without extensive public cryptanalysis. For production, use AES-256-GCM or ChaCha20-Poly1305.

Command Line Usage

# Encrypt a file
chaco256 encrypt input.txt output.enc

# Decrypt a file
chaco256 decrypt output.enc decrypted.txt --key output.enc.key

# Generate a key
chaco256 keygen --output my.key

# Encrypt text
chaco256 encrypt-text "Hello, World!"

# Get help
chaco256 --help

Python API - Basic Encryption

import chaco256

# Generate key and nonce
key = chaco256.generate_key()
nonce = chaco256.generate_nonce()

# Create AEAD cipher
aead = chaco256.Chaco256Aead(key)

# Encrypt
message = "Hello, World!"
plaintext = message.encode('utf-8')
ciphertext, tag = aead.encrypt(nonce, plaintext, b"")

# Decrypt
decrypted = aead.decrypt(nonce, ciphertext, tag, b"")
print(decrypted.decode('utf-8'))  # Hello, World!

Examples

File Encryption

import chaco256

def encrypt_file(input_path, output_path, key):
    # Read file
    with open(input_path, 'rb') as f:
        plaintext = f.read()
    
    # Generate nonce
    nonce = chaco256.generate_nonce()
    
    # Encrypt
    aead = chaco256.Chaco256Aead(key)
    ciphertext, tag = aead.encrypt(nonce, plaintext, b"")
    
    # Write: nonce + ciphertext + tag
    with open(output_path, 'wb') as f:
        f.write(nonce + ciphertext + tag)

# Usage
key = chaco256.generate_key()
encrypt_file("document.txt", "document.enc", key)

String Encryption

import chaco256

key = chaco256.generate_key()
nonce = chaco256.generate_nonce()
aead = chaco256.Chaco256Aead(key)

# Encrypt a string
message = "Secret message"
plaintext = message.encode('utf-8')
ciphertext, tag = aead.encrypt(nonce, plaintext, b"")

# Decrypt back to string
decrypted_bytes = aead.decrypt(nonce, ciphertext, tag, b"")
decrypted_message = decrypted_bytes.decode('utf-8')
print(decrypted_message)  # Secret message

AEAD with Associated Data

import chaco256

key = chaco256.generate_key()
nonce = chaco256.generate_nonce()
aead = chaco256.Chaco256Aead(key)

# Encrypt with associated data
message = "Confidential data"
plaintext = message.encode('utf-8')
associated_data = b"Public header"

ciphertext, tag = aead.encrypt(nonce, plaintext, associated_data)

# Decrypt and verify
try:
    decrypted = aead.decrypt(nonce, ciphertext, tag, associated_data)
    print(decrypted.decode('utf-8'))
    print("Authentication successful")
except ValueError:
    print("Authentication failed!")

API Reference

chaco256.generate_key()

Generate a random 256-bit encryption key.

key = chaco256.generate_key()  # Returns 32 bytes

chaco256.generate_nonce()

Generate a random 192-bit nonce.

nonce = chaco256.generate_nonce()  # Returns 24 bytes

chaco256.Chaco256Aead(key, rounds=20)

AEAD cipher for authenticated encryption.

aead = chaco256.Chaco256Aead(key)

# Encrypt
ciphertext, tag = aead.encrypt(nonce, plaintext, associated_data)

# Decrypt
plaintext = aead.decrypt(nonce, ciphertext, tag, associated_data)
